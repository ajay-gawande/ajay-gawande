### PROJECT 002 — INTELLIGENT IOT APPLICATION

# SpectraOil

**Connecting hardware, mobile development and machine learning.**

An IoT-enabled Android application designed to estimate cooking oil quality using spectral sensor readings and an ONNX machine learning model.

**System architecture**

```text
AS7343 Spectral Sensor
          |
          v
       ESP32
          |
          v
   Bluetooth Serial
          |
          v
    Android Application
          |
          v
     ONNX Runtime
          |
          v
   Quality Prediction
```

**Engineering highlights**

- Integrated ESP32 with AS7343 spectral sensor.
- Implemented Bluetooth communication.
- Transmitted spectral channel readings.
- Integrated ONNX Runtime for machine learning inference.
- Developed Android application functionality.

`Java` `Android Studio` `ESP32` `AS7343` `Bluetooth` `ONNX`
